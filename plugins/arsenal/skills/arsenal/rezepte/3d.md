## Rahmen für jede Szene

Die Szene läuft nur im Bild und wird beim Verlassen abgebaut (TE10). Beim Abbau gibt R3F Renderer und deklarierte Objekte frei. Bei reduzierter Bewegung steht das Standbild (S17). Der Knopf hält die Szene an und zeigt das Standbild (S18, Pflicht bei allem, was länger als 5 s von selbst läuft). Pixeldichte nach `regler.md`, auf dem Telefon 1. Die Größe des Rahmens fest per CSS setzen, damit nichts springt.

```jsx
import { useEffect, useRef, useState } from 'react'

export function SceneFrame({ still, alt = '', children }) {
  const ref = useRef(null)
  const [s, setS] = useState({ visible: false, reduced: true, coarse: false })
  const [paused, setPaused] = useState(false)
  useEffect(() => {
    const reduced = matchMedia('(prefers-reduced-motion: reduce)').matches
    const coarse = matchMedia('(pointer: coarse)').matches
    const io = new IntersectionObserver(([e]) =>
      setS({ visible: e.isIntersecting, reduced, coarse }))
    io.observe(ref.current)
    return () => io.disconnect()
  }, [])
  const dpr = s.coarse ? 1 : [1, 1.5]
  return (
    <div ref={ref} className="szene">
      {s.visible && !s.reduced && !paused
        ? children({ dpr, coarse: s.coarse })
        : <img src={still} alt={alt} />}
      {!s.reduced && (
        <button className="szene-pause" aria-pressed={paused} aria-label="Bewegung anhalten"
                onClick={() => setPaused((p) => !p)}>…</button>
      )}
    </div>
  )
}
```

In Astro als Insel mit `client:visible` (TE03, `rezepte/astro.md`). Selbst angelegte Geometrien, Materialien und Texturen beim Abbau mit `.dispose()` freigeben.

## Schwebendes Objekt

drei `Float` lässt ein einzelnes Objekt schweben und drehen.

```jsx
import { Canvas } from '@react-three/fiber'
import { Float, Environment } from '@react-three/drei'
import { SceneFrame } from './SceneFrame'

export default function Hero3D() {
  return (
    <SceneFrame still="/hero-still.webp">
      {({ dpr }) => (
        <Canvas camera={{ position: [0, 0, 5], fov: 40 }} dpr={dpr}>
          <ambientLight intensity={0.4} />
          <directionalLight position={[3, 3, 3]} intensity={1.2} />
          <Float speed={1.5} rotationIntensity={0.6} floatIntensity={0.8}>
            <mesh>
              <icosahedronGeometry args={[1, 1]} />
              <meshPhysicalMaterial
                color="#2b2f77"
                roughness={0.15}
                metalness={0.1}
                clearcoat={1}
                transmission={0.15}
              />
            </mesh>
          </Float>
          <Environment files="/hdri/city-1k.hdr" />
        </Canvas>
      )}
    </SceneFrame>
  )
}
```

`meshPhysicalMaterial` statt der Vorgaben von `meshStandardMaterial`, Farbe aus der Marke. Geometrie aus dem Produkt ableiten (gefaltete Karte, extrudiertes Zeichen, Low-Poly-Fassung eines echten Gegenstands).

## Scrollgekoppeltes Objekt

Der Scrollstand wird im `useFrame` gelesen, ohne Scroll-Handler; die Seitenhöhe wird nur bei Größenänderung gemessen, nie je Bild (TE11). Die Kopplung ist linear (BE12).

```jsx
import { useEffect, useRef } from 'react'
import { Canvas, useFrame } from '@react-three/fiber'
import { SceneFrame } from './SceneFrame'

function ScrollObject() {
  const ref = useRef()
  const max = useRef(1)
  useEffect(() => {
    // TE11: measure layout on resize only, never per frame
    const measure = () => {
      max.current = Math.max(1, document.documentElement.scrollHeight - window.innerHeight)
    }
    const ro = new ResizeObserver(measure)
    ro.observe(document.documentElement)
    addEventListener('resize', measure)
    return () => { ro.disconnect(); removeEventListener('resize', measure) }
  }, [])
  useFrame(() => {
    if (!ref.current) return
    const p = Math.min(1, window.scrollY / max.current)
    ref.current.rotation.y = p * Math.PI * 2
    ref.current.position.y = -p * 2
  })
  return (
    <mesh ref={ref}>
      <torusGeometry args={[1, 0.35, 32, 100]} />
      <meshStandardMaterial color="#e8542a" roughness={0.3} />
    </mesh>
  )
}

export default function ScrollScene() {
  return (
    <SceneFrame still="/scroll-still.webp">
      {({ dpr }) => (
        <Canvas dpr={dpr} camera={{ position: [0, 0, 5] }}>
          <ambientLight intensity={0.5} />
          <directionalLight position={[2, 2, 2]} />
          <ScrollObject />
        </Canvas>
      )}
    </SceneFrame>
  )
}
```

Statt der reinen Drehung etwas Bauliches koppeln: ein Objekt, das sich zusammensetzt, eine Kamerafahrt zu einem Detail.

## Punktfeld

Ein `Points`-Feld ist ein einziger Draw Call. Nur `three` und `@react-three/fiber`.

```jsx
import { useMemo, useRef } from 'react'
import { Canvas, useFrame } from '@react-three/fiber'
import { SceneFrame } from './SceneFrame'

function Particles({ count = 800 }) {
  const ref = useRef()
  const positions = useMemo(() => {
    const arr = new Float32Array(count * 3)
    for (let i = 0; i < count * 3; i++) arr[i] = (Math.random() - 0.5) * 8
    return arr
  }, [count])

  useFrame((_, delta) => {
    if (ref.current) ref.current.rotation.y += delta * 0.03
  })

  return (
    <points ref={ref}>
      <bufferGeometry>
        <bufferAttribute attach="attributes-position" args={[positions, 3]} />
      </bufferGeometry>
      <pointsMaterial size={0.03} color="#9aa0ff" sizeAttenuation transparent opacity={0.7} />
    </points>
  )
}

export default function ParticleScene() {
  return (
    <SceneFrame still="/particles-still.webp">
      {({ dpr, coarse }) => (
        <Canvas dpr={dpr} camera={{ position: [0, 0, 5] }}>
          <Particles count={coarse ? 400 : 800} /> {/* example: fewer points on phones (TE10) */}
        </Canvas>
      )}
    </SceneFrame>
  )
}
```

Hunderte Punkte, nicht Zehntausende. Farbe aus der Marke.

## GLB-Modell laden

drei `useGLTF` lädt und cacht `.glb`/`.gltf` mit Suspense. Modelllizenzen gelten je Datei und sind vor dem Einsatz zu prüfen (Quellen unten).

```jsx
import { Suspense } from 'react'
import { Canvas } from '@react-three/fiber'
import { useGLTF, Environment, ContactShadows } from '@react-three/drei'
import { SceneFrame } from './SceneFrame'

function Model(props) {
  const { scene } = useGLTF('/models/product.glb')
  return <primitive object={scene} {...props} />
}
useGLTF.preload('/models/product.glb')

export default function ModelViewer() {
  return (
    <SceneFrame still="/product-still.webp" alt="Produkt">
      {({ dpr }) => (
        <Canvas dpr={dpr} camera={{ position: [0, 1, 4], fov: 35 }}>
          <ambientLight intensity={0.6} />
          <Suspense fallback={null}>
            <Model scale={1.2} />
            <Environment files="/hdri/studio-1k.hdr" />
            <ContactShadows opacity={0.4} blur={2.5} far={2} />
          </Suspense>
        </Canvas>
      )}
    </SceneFrame>
  )
}
```

Fremde Modelle auf die Markenfarben umfärben. In Claude-Artefakten gelten TE16 (three.js laden) und TE17 (Modell als Base64).

## Licht aus HDRI

drei `Environment` setzt bildbasiertes Licht aus einem HDRI. Die eingebauten Presets (`"city"`, `"studio"`, `"sunset"`, `"warehouse"` usw.) holt drei von einem fremden CDN. Darum laden alle Beispiele hier eine selbst gehostete Datei mit `files`, etwa ein HDRI von Poly Haven (CC0) unter `public/hdri/` (S09).

```jsx
import { Environment } from '@react-three/drei'

// inside a <Canvas>:
<Environment files="/hdri/sunset-1k.hdr" background blur={0.6} />
```

`blur` einstellen, ein HDRI in Richtung Markenton wählen, oder `background={false}`, damit das HDRI nur beleuchtet und der Seitenhintergrund bleibt.

## Ohne Code: Spline

[Spline](https://spline.design) ist ein 3D-Werkzeug im Browser und exportiert Szenen zum Einbetten.

- Gratisstufe gibt es weiter (Stand Sep 2026): unbegrenzte Betrachter, begrenzte Dateizahl. Exporte tragen ein Wasserzeichen, das erst bezahlte Stufen entfernen (Starter etwa 12 bis 15 $/Monat).
- Einbettung: `@splinetool/react-spline`, MIT, aktuelle Major v4.x. Ohne Framework: `@splinetool/runtime`.
- Datenschutz (S09): Die Adresse `prod.spline.design` im Beispiel ist ein Fremdserver. Die `.splinecode`-Datei selbst hosten oder die Freigabe je Fall einholen. Ob die Laufzeit weitere Dateien von fremden Servern nachlädt, ist ungeprüft; im Netzprotokoll nachsehen.

```bash
npm install @splinetool/react-spline
```

```jsx
import Spline from '@splinetool/react-spline'
import { SceneFrame } from './SceneFrame'

export default function SplineScene() {
  return (
    <SceneFrame still="/spline-still.webp">
      {() => <Spline scene="https://prod.spline.design/your-scene-id/scene.splinecode" />}
    </SceneFrame>
  )
}
```

Spline passt, wenn Gestalter ohne Entwickler die Szene pflegen und sie für sich steht. R3F von Hand passt, wenn Leistung messbar sein muss (die Spline-Laufzeit lässt sich weder tree-shaken noch zeilenweise profilen), keine zweite Laufzeit neben `three` kommen soll oder die Szene an React-Zustand und Scroll hängt.

## Fallen aus Paulis Churros (26.09.2026)

- **GLB aus Blender ohne Texturen:** Prozedurale Blender-Materialien (Holz, Schindeln) überleben den glTF-Export nicht, übrig bleibt die Grundfarbe. Ohne neuen Bake hilft Weltkoordinaten-Projektion (triplanar) per `onBeforeCompile`, zugeordnet über Materialnamen: CC0-Sätze (Poly Haven, ambientCG) mit Farbe, Normal (OpenGL) und Rauheit, Farbe als `Grundfarbe * Textur / Mittelfarbe der Textur`, damit der Farbton des Modells bleibt. Im Fragment-Shader steht `normal` bei `map_fragment` noch nicht bereit: die Weltnormale aus `vNormal` und `gl_FrontFacing` bilden.
- **Lichtfarbe nie über den Farbton überblenden:** `setHSL(mix(orange, blau))` läuft durch Grün, die Mitte der Dämmerung bekommt einen Grünstich. Immer `Color.lerp` zwischen zwei fertigen Farben.
- **Lichthöfe als additive Points:** mit `premultipliedAlpha: true` und Ausgabe-Alpha 0, sonst schreiben ausgeschaltete Höfe schwarze Quadrate in eine transparente Leinwand. Keine Höfe für Birnen, die in Blickrichtung hintereinander liegen (Seitentraufe), sonst addieren sie sich zu einem Fleck.
- **Birnen einzeln einschalten:** zusammenhängende Teilnetze per Union-Find über den Index finden, je Birne ein Vertex-Attribut `aOrdnung`. Die Reihenfolge nach Rang vergeben, nicht nach Abstand, sonst frisst eine lange Außenkette die Zeit.
